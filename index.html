DESIGN STUDY / 5 PATTERNS — FOR PRODUCTION HANDOFF

月が昇る。
浦和の祭りが始まる。

2026年9月19日（土）東京ヴェルディ戦。「炎日」初の秋開催を題材に、月・九・兎・櫓・浦和おどり・試合への熱を、それぞれ異なる思想で組み立てた特設ページ5案です。すべてスマートフォン対応、JavaScript無効でも主要情報を閲覧できます。

モック一覧

5つの思想、5つのページ。

PATTERN 01 / INTERACTIVE

九灯の月夜

九つの提灯を灯しながら、イベント情報を巡る。最も祭りらしく、最も分かりやすい参加型案。

PATTERN 02 / STORYTELLING

月影絵巻

静かな月夜から、芸能、総踊り、試合へ。縦スクロールを一日の物語として設計する案。

PATTERN 03 / DISCOVERY

月兎の道しるべ

兎の足跡を追うと、浦和と月の関係が見えてくる。ファミリーにも開かれた探索型案。

PATTERN 04 / EDITORIAL

9.19 FESTIVAL TICKET

日付を主役にしたチケット／ポスター型。情報整理とチケット購入導線を最も強くした案。

PATTERN 05 / GATHERING

ひとつの輪

複数の出演団体、来場者、クラブを一つの輪にまとめる。浦和おどりを中心にした共同体型案。

共通方針

5案に共通する制約と品質基準。

技術方針

スマートフォン対応。JavaScriptが動かなくても主要情報を閲覧可能。prefers-reduced-motion 対応。Webフォント・写真は使用可（詳細は ASSETS.md）。

情報設計

ファーストビュー、固定ナビ、ページ末尾にチケット導線。時間・場所・料金・対象・雨天時対応などの必須情報を明記。

仮情報の扱い

記載されているイベント内容・時間・場所はすべてモック上の仮情報です。差し替え箇所は assets/data/event.json に集約しています。

事実確認が必要な項目

調神社や兎の由来など（案3）を本番で掲載する場合は、事実確認・関係者確認を前提とします。
