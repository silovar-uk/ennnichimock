DESIGN STUDY / 5 PATTERNS

月が昇る。
浦和の祭りが始まる。

2026年9月19日（土）東京ヴェルディ戦。「炎日」初の秋開催を題材に、 月・九・兎・櫓・浦和おどり・試合への熱を、それぞれ異なる思想で組み立てた特設ページモック。 すべてスマートフォン対応、外部ライブラリ不使用、GitHub Pagesでそのまま閲覧可能な静的サイトです。

PATTERN 01 / INTERACTIVE

九灯の月夜

九つの提灯を灯しながら、イベント情報を巡る。最も祭りらしく、最も分かりやすい参加型案。
PATTERN 02 / STORYTELLING

月影絵巻

静かな月夜から、芸能、総踊り、試合へ。縦スクロールを一日の物語として設計する案。
PATTERN 03 / DISCOVERY

月兎の道しるべ

兎の足跡を追うと、浦和と月の関係が見えてくる。ファミリーにも開かれた探索型案。
PATTERN 04 / EDITORIAL

9.19 FESTIVAL TICKET

日付を主役にしたチケット／ポスター型。情報整理とチケット購入導線を最も強くした案。
PATTERN 05 / GATHERING

ひとつの輪

複数の出演団体、来場者、クラブを一つの輪にまとめる。浦和おどりを中心にした共同体型案。
