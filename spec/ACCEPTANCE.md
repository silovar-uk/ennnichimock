## 機能・情報到達

- [ ] JavaScript無効時、5案すべてで必須情報（日時・会場・料金・対象・雨天時対応・アクセス・問い合わせ）に到達できる
- [ ] `prefers-reduced-motion: reduce` で全案の装飾アニメーションが停止する
- [ ] モバイル代表幅（360 / 390 / 430px）で崩れがない
- [ ] タブレット・PC代表幅（768 / 1024 / 1440px）で崩れがない
- [ ] 見出し階層の飛びがゼロ、ランドマーク重複がゼロ、フォーカス可視率100%（A11Y.md準拠）
- [ ] 印刷プレビューで日時・会場・タイムテーブル・問い合わせ先が1ページに収まる
- [ ] OGP画像・favicon・JSON-LD（`SportsEvent`）が全ページで有効（構造化データテストツールで確認）
- [ ] 404ページが用意されている
- [ ] `assets/data/event.json` の値を書き換えるだけで、全ページの該当箇所（`data-src`）が更新される

## コンテンツ

- [ ] 仮情報バッジ・告知バナーの文言が本番確定情報に差し替わっている、または `event.json` の `meta.provisional` が `false` になっている
- [ ] 案3の由来紹介文について、事実確認・関係者確認の結果が反映されている（COPY.md参照）
- [ ] 「〜する想定です」等のモック解説文が本文に残っていない
