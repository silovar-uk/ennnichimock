# A11Y.md — アクセシビリティ仕様

目標：WCAG 2.2 レベルAA準拠。

## 達成基準チェックリスト

- [ ] **コントラスト比**：本文文字 4.5:1 以上、大きな文字（24px相当以上または太字18.5px以上）3:1 以上。全案・全トークン組み合わせで確認（DESIGN-TOKENS.md の案別差分表を含む）。
- [ ] **フォーカス可視性**：すべてのインタラクティブ要素に `:focus-visible` によるアウトラインが表示される（`typography.css` で全要素共通定義済み）。カスタムコンポーネント（提灯ボタン、FAQ、ビルダーのチェックボックス）で上書き・消去していないことを確認。
- [ ] **見出し階層**：h1は1ページに1つ。h2→h3の飛び番なし。
- [ ] **ランドマーク**：`nav` `main` `footer` の重複がないこと。セクションには `aria-labelledby` で見出しと関連付け。
- [ ] **キーボード操作のみで全機能に到達できる**：提灯トグル（案1）、FAQアコーディオン、モデルコースビルダーのチェックボックス（案4）、モバイルナビの開閉。
- [ ] **スキップリンク**：`.skip-link` が全ページに設置され、Tab最初のフォーカスで出現する。
- [ ] **代替テキスト**：装飾目的のSVG（提灯・月・輪など）は `aria-hidden="true"`。情報を持つ図（案5の輪の図）は `role="img"` + `aria-label` で内容を文章化済み。
- [ ] **motion**：`prefers-reduced-motion: reduce` で以下が停止すること：案1のトランジション、案2の月軌道アニメーション、案3の兎ホップ、案5のリング回転。
- [ ] **フォームラベル**：案4のチェックボックスは `<label>` で `<input>` を包み、クリック領域とラベルが一致している。
- [ ] **言語指定**：`<html lang="ja">` を全ページで設定済み。

## 検証手順

1. **自動検証**：axe DevTools または Lighthouse Accessibility スコアを全5案 + indexで計測し、`ACCEPTANCE.md` に実測値を記録する。
2. **キーボードのみ操作**：マウスを使わず、Tab/Shift+Tab/Enter/Spaceのみで全セクションの主要機能（提灯を灯す、FAQを開く、ビルダーで項目を選ぶ、ナビを開閉する）が実行できることを確認する。
3. **スクリーンリーダー確認**：VoiceOver（Safari）またはNVDA（Firefox）で、見出しジャンプ・リンクリスト・フォーム操作を通しで確認する。
4. **200%ズーム**：レイアウト崩れ・テキストの重なりがないことを確認する。
5. **reduced motion**：OS設定で「視差効果を減らす」を有効化し、各案のサイン要素アニメーションが停止することを目視確認する。
