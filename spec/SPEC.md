# SPEC.md — 炎日 2026 特設ページ 発注仕様

対象: 浦和レッズ「炎日 2026」（2026年9月19日(土) 東京ヴェルディ戦 / 埼玉スタジアム）特設ページ。
本書は5案のデザインモックを制作会社へ発注する際の仕様書です。実装は本リポジトリの静的HTML/CSS/JSを参照実装とし、本番構築時のCMS・フレームワークは問いません。

## 1. 背景と目的

- 「炎日」は毎年開催してきた浦和レッズの試合前イベントで、2026年は初めて秋（9/19）に開催する。
- 特設ページの目的は (1) 来場動機の醸成、(2) 当日の過ごし方の案内、(3) チケット購入への誘導。
- 5案はいずれも同じ情報（時間・場所・料金・対象・雨天時対応）を扱うが、伝え方の思想が異なる。**発注側はこの中から1〜複数案を選び、本仕様に基づき本番品質へ仕上げることを想定する。**

## 2. 情報設計（IA）— 5案共通

1. ファーストビュー（思想の提示、日付・キックオフ・会場）
2. 案固有のメインコンテンツ（後述の各案仕様を参照）
3. タイムテーブル（14:00 開始 〜 18:30 キックオフ）
4. FAQ（必須5項目、COPY.md参照）
5. チケット購入CTA（ページ末尾・固定ナビ両方に設置）
6. フッター（他案比較への導線を含む）

固定ナビは全案に共通（ロゴ／セクションアンカー／チケットCTA／モバイル用ハンバーガー）。

## 3. 案別のコンセプトと固有要件

| 案 | 固有要件 |

| 01 九灯の月夜 | 9つの提灯トグル、月相インジケータ（0〜9灯で連動）。JS無効時は全項目を可視状態で提供。 |

## 4. 機能要件

- チケット購入CTAの遷移先（実URL）は発注時に確定する。本モックでは `#top` のダミーリンク。
- モデルコースビルダー（案4）はクライアントサイドのみで完結。外部APIとの通信、個人情報の取得・保存は行わない。
- お知らせ更新時は `.notice-banner` の文言を差し替える運用を想定（CMSのバナー機能等で代替可）。

## 5. 非機能要件

- **対応ブラウザ**：モバイルSafari（直近2バージョン）、Chrome for Android（直近2バージョン）、Chrome/Edge/Firefox/Safari 各最新2バージョン。
- **レスポンシブ**：360px〜。360/390/430/768/1024/1440の代表幅で目視確認。
- **パフォーマンス**：LCP < 2.0s（4G相当）、CLS < 0.02、INP < 200ms。Lighthouse モバイル Performance ≥ 95。
- **アクセシビリティ**：WCAG 2.2 AA準拠を目標。詳細は A11Y.md。
- **motion**：`prefers-reduced-motion: reduce` 環境では装飾的アニメーションを完全に停止する。
- **JS非依存性**：JavaScriptを無効化しても、必須情報（日時・会場・料金・対象・雨天時対応・アクセス・問い合わせ）に100%到達できること。
- **印刷**：印刷時、日時・会場・タイムテーブル・問い合わせ先が1ページに収まるレイアウトを用意する（`@media print`）。

## 6. データと差し替え運用

- すべての可変値（日時・会場・スケジュール・9つの楽しみ・FAQ）は `assets/data/event.json` に集約する。
- 本文HTMLには実値を静的に書き出した上で `data-src="path.to.key"` を付与し、`data-render.js` が任意でハイドレートする（JS無効でも静的値がそのまま正しい表示になる設計）。
- 仮情報である間はUI上に `.provisional-flag`（仮情報バッジ）を表示する。本番確定後は `event.json` の `meta.provisional` を `false` にし、バッジを一括除去する（`data-render.js` が対応済み）。

## 7. スコープ外（本モックに含まれないもの）

- 実写真・実映像素材そのもの（規格のみ ASSETS.md に定義。素材調達・権利処理は別途）
- チケット購入システムとの実連携、決済、在庫管理
- 多言語対応（英語版など）
- CMS実装、更新用管理画面
- 実アクセス解析・広告タグの実装（設置箇所の想定のみ）
- 調神社・兎の由来等、事実確認が未了の郷土史コンテンツの本文確定（案3。要関係者確認）

## 8. 発注時に確認すべき事項（本書では意思決定していない項目）

- 採用する案の数（1案 / 複数案の出し分け）
- 写真素材の調達方法（クラブ保有素材／制作会社調達／プロカメラマン契約）
- チケット購入導線の実際の遷移先（クラブ公式チケットサイト等）
- 郷土史コンテンツ（案3）の掲載可否と、掲載する場合の確認プロセス
- アクセス解析・広告タグの有無と種類
