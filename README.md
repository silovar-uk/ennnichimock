# 炎日 2026 特設ページ モック

2026年9月19日（土）東京ヴェルディ戦で予定される「炎日」初の秋開催を題材にした、特設ページのデザインスタディです。

## モック一覧

1. `pattern-1.html` — 九灯の月夜
   - 九つの提灯を灯しながら情報を巡る参加型
   - 「9」をページ構造として使用
   - 祭りらしさと実用性のバランスを重視

2. `pattern-2.html` — 月影絵巻
   - 月が昇り、祭りから試合へ進む縦スクロール型
   - 静から動への感情設計
   - 一日の時間を物語として編集

3. `pattern-3.html` — 月兎の道しるべ
   - 兎の足跡を追いながら情報を発見
   - 月・兎と浦和の関係をページ後半で回収
   - ファミリー、初来場者にも開かれた設計

4. `pattern-4.html` — 9.19 FESTIVAL TICKET
   - 日付を大きく扱うチケット／ポスター型
   - 9つの楽しみとモデルコース生成
   - 告知・SNS・チケット購入導線との連携を重視

5. `pattern-5.html` — ひとつの輪
   - 出演団体、来場者、櫓、試合を「輪」で統合
   - 浦和おどりをイベントの中心に配置
   - 団体数の多さを一体感として表現

## 共通方針

- スマートフォン対応
- 外部ライブラリ・外部フォント・外部画像不使用
- JavaScriptが動かなくても主要情報を閲覧可能
- `prefers-reduced-motion` 対応
- ファーストビュー、固定ナビ、ページ末尾にチケット導線
- 時間・場所・料金・対象・雨天時対応などの必須情報を想定
- 記載されているイベント内容・時間・場所はすべてモック上の仮情報
- 調神社や兎の由来を本番で掲載する場合は、事実確認・関係者確認を前提とする

## 閲覧方法

`index.html` をブラウザで開くと、5案の比較ページが表示されます。
GitHub Pagesを利用する場合は、リポジトリの Pages 設定で `main` ブランチのルートを公開元に設定してください。
